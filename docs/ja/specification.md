# 仕様の対応状況

各観点は `@pytest.mark.spec` を付けたテストで実証されたときだけ `done` になるため、
実装済みでも仕様テストのタグ付けがまだの機能は `planned` に含まれます。下の表は生成物のため英語のみです。

リリース版の対応範囲は、[リリース一覧](https://github.com/yhay81/pyropdf/releases)で
該当するタグを選び、`capabilities.zip` を開くと確認できます。リリースノートも同じファイルへ案内します。
報告書には、読み取り・作成・編集などの役割、検証した操作、対象外の項目、制限を記載します。
入力側のプロファイル、外部エンジン、任意の実行環境も区別して示します。
0.3.1 はこの仕組みより前のリリースで、検証済みの対応範囲は公表されていません。
