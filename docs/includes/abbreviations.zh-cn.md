*[AES-256]: 采用 256 位密钥的高级加密标准（Advanced Encryption Standard），是 PDF 规范中最强的加密方式
*[CCITT]: 黑白图像的传真压缩标准（Group 3 与 Group 4）
*[CJK]: 中文、日文与韩文（Chinese, Japanese, and Korean）
*[CMS]: 加密消息语法（Cryptographic Message Syntax，RFC 5652），用于封装 PDF 数字签名
*[CropBox]: 查看器实际显示的页面区域；pyropdf 会将其裁剪到 MediaBox 范围内
*[GIL]: 全局解释器锁（Global Interpreter Lock），同一时刻仅允许一个线程执行 Python 字节码
*[ISO 32000-2]: PDF 2.0 国际标准规范
*[JBIG2]: 面向黑白扫描图像的压缩格式
*[MediaBox]: 页面打印介质的边界框
*[OCR]: 光学字符识别（Optical Character Recognition），从扫描页面的像素中识别文字
*[PAdES]: PDF 高级电子签名（PDF Advanced Electronic Signatures），ETSI 制定的 PDF 签名配置文件（EN 319 142）
*[PDF/A]: ISO 19005，用于长期归档的 PDF 标准
*[PDF/UA]: ISO 14289，用于通用无障碍访问的 PDF 标准
*[RFC 3161]: 时间戳协议，用于生成证明数据存在时间的令牌
