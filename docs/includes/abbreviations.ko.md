*[AES-256]: 256비트 키를 사용하는 고급 암호화 표준(Advanced Encryption Standard)으로, PDF가 표준화한 가장 강력한 암호화 방식
*[CCITT]: 흑백 이미지용 팩스 압축 방식(Group 3 및 Group 4)
*[CJK]: 중국어, 일본어, 한국어(Chinese, Japanese, and Korean)
*[CMS]: 암호화 메시지 구문(Cryptographic Message Syntax, RFC 5652)으로, PDF 서명을 담는 컨테이너
*[CropBox]: 뷰어가 표시하는 페이지 영역이며, pyropdf는 이를 MediaBox 범위로 잘라냅니다
*[GIL]: 전역 인터프리터 잠금(Global Interpreter Lock)으로, 한 번에 하나의 스레드만 Python 바이트코드를 실행하도록 제어
*[ISO 32000-2]: PDF 2.0 국제 표준 명세
*[JBIG2]: 흑백 스캔 이미지를 위한 압축 형식
*[MediaBox]: 페이지가 인쇄되는 매체의 경계 상자
*[OCR]: 광학 문자 인식(Optical Character Recognition)으로, 스캔된 페이지의 픽셀에서 텍스트를 읽는 기술
*[PAdES]: PDF 고급 전자 서명(PDF Advanced Electronic Signatures)으로, ETSI의 PDF 서명 프로파일(EN 319 142)
*[PDF/A]: ISO 19005, 장기 보존을 위한 PDF 표준
*[PDF/UA]: ISO 14289, 보편적 접근성을 위한 PDF 표준
*[RFC 3161]: 타임스탬프 프로토콜로, 데이터가 특정 시점에 존재했음을 증명하는 토큰
