*[AES-256]: The Advanced Encryption Standard with 256-bit keys, the strongest encryption that PDF standardizes
*[CCITT]: The fax compression of black-and-white images, Group 3 and Group 4
*[CJK]: Chinese, Japanese, and Korean
*[CMS]: Cryptographic Message Syntax (RFC 5652), the container that holds a PDF signature
*[CropBox]: The page box that a viewer shows; pyropdf clips it to the MediaBox
*[GIL]: The global interpreter lock, which lets one thread at a time run Python bytecode
*[ISO 32000-2]: The PDF 2.0 specification
*[JBIG2]: A compression format for black-and-white scanned images
*[MediaBox]: The page box of the medium that the page is printed on
*[OCR]: Optical character recognition: reading text from the pixels of a scanned page
*[PAdES]: PDF Advanced Electronic Signatures, the ETSI profile of PDF signatures (EN 319 142)
*[PDF/A]: ISO 19005, PDF for long-term archiving
*[PDF/UA]: ISO 14289, PDF for universal accessibility
*[RFC 3161]: The time-stamp protocol: a token that proves when data existed
