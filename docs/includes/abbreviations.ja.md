*[AES-256]: 256 ビット鍵の Advanced Encryption Standard。PDF が標準化する中で最も強い暗号化
*[CCITT]: 白黒画像のファクス圧縮（Group 3 と Group 4）
*[CJK]: 中国語・日本語・韓国語
*[CMS]: Cryptographic Message Syntax（RFC 5652）。PDF の署名を収める入れ物
*[CropBox]: ビューアが表示するページの枠。pyropdf は MediaBox で切り詰めます
*[GIL]: グローバルインタプリタロック。Python のバイトコードを一度に一つのスレッドだけが実行するためのロック
*[ISO 32000-2]: PDF 2.0 の仕様
*[JBIG2]: 白黒のスキャン画像の圧縮形式
*[MediaBox]: ページを印刷する媒体の枠
*[OCR]: 光学文字認識。スキャンしたページの画素から文字を読み取ること
*[PAdES]: PDF Advanced Electronic Signatures。ETSI による PDF 署名のプロファイル（EN 319 142）
*[PDF/A]: ISO 19005。長期保存のための PDF
*[PDF/UA]: ISO 14289。アクセシビリティのための PDF
*[RFC 3161]: タイムスタンプのプロトコル。データがいつ存在したかを証明するトークン
